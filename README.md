# First Response VR

An interactive VR first-aid training simulation for the **Meta Quest 2**, built in Unity for the TSA State competition.

You respond to three emergencies with your own hands:

| Scenario | Where | What you practise |
|---|---|---|
| **Severe Bleeding** | A park path, after a cyclist falls on broken glass | Scene safety, calling 911, gloves, a dressing on the wound, firm continuous pressure, adding a dressing when blood soaks through, bandaging, checking circulation, keeping the person warm |
| **Infant Choking** | A living room | Recognising severe choking, getting 911 called, 5 back blows (face-down, head low), 5 chest thrusts (face-up, heel of hand), repeating until the object comes out, monitoring |
| **Shock** | A trailhead rest area | Recognising shock, calling 911, helping the person lie flat, raising the feet (no injury), keeping them warm, no food or drink, reassurance, monitoring breathing |

Each scenario can be played in two modes:

- **Training Mode** gives step-by-step instructions, highlights the next object, and gives instant feedback on correct and incorrect actions.
- **Certification Mode** gives no instructions or hints and has a time limit. Every action is recorded, and you pass with 80% or more, no missed critical steps and no critical mistakes.

At the end of every run, a **performance dashboard** shows:
- the overall score, technical proficiency and response efficiency
- correct and incorrect actions, and missed critical steps
- the time taken
- a step checklist, a timeline chart, and areas for improvement

> Educational simulation only. It does not replace certified first-aid training (American Red Cross, American Heart Association). In a real emergency, call 911.

## Requirements

- **Unity version: the team still needs to decide.**
  - The repo's first commit was made with Unity **6000.0.32f1**.
  - This simulation was built and tested in **6000.6.4f1**. Opening the project in that editor upgraded the packages to XRI 3.6.1, OpenXR 1.18 and URP 17.6.
  - Everyone must use the same version. Opening the project in an older editor than the one that last saved it can break it.
- **Android Build Support** for Unity 6000.6.4f1, with **OpenJDK** and **Android SDK & NDK Tools**. Add these in Unity Hub > Installs > ⚙ > Add modules. They are needed only to build for the Quest.
- **A Meta Quest 2** with Developer Mode on, to install builds. Other Quest headsets use the same OpenXR setup but have not been tried.

## Getting started

1. Clone the repo and open the folder in Unity Hub with **Unity 6000.6.4f1**.
2. Open `Assets/FirstAidVR/Scenes/MainMenu.unity`.
3. Press **Play**. There are two ways to play in the editor:
   - **With a headset:** connect the Quest with Link / Air Link.
   - **Without a headset:** turn on **Tools > First Aid VR > Desktop Simulator (no headset)**. You can then play with keyboard and mouse. Turn it off again before using Link.

## Building for Quest 2

1. Install Android Build Support (see Requirements).
2. **Tools > First Aid VR > Configure for Quest 2.** This sets the Android player settings and the OpenXR Meta Quest feature:
   - product name **First Response VR**, company "TSA State VR Team", package id `com.tsastate.firstresponsevr`
   - IL2CPP, ARM64, minimum API 32, Vulkan
   - Meta Quest feature + Touch profiles on, Android XR (non-Quest) features off

   **Build All Scenes** also replaces the Build Settings scene list with the four simulation scenes; the template's SampleScene is no longer in it.
3. Choose **File > Build Profiles > Android > Switch Platform**.
4. Plug in the Quest. **Build And Run** installs the app straight to the headset. Alternatively, **Tools > First Aid VR > Build Quest 2 APK** writes `Builds/FirstResponseVR.apk`.
5. On the headset, the app is under **Library > Unknown Sources**.

## Project tools (menu: Tools > First Aid VR)

| Menu item | What it does |
|---|---|
| Build All Scenes | Regenerates the 4 scenes from code (see note below) |
| Configure for Quest 2 | Android + OpenXR settings for Quest |
| Build Quest 2 APK | Builds the APK into `Builds/` |
| Desktop Simulator (no headset) | Lets you test in Play mode with keyboard and mouse |
| Reset Scenario Content | Resets the step and mistake text to the defaults in `ScenarioContent.cs` |
| Write XR Report | Lists the enabled XR features in `Logs/FirstAidXRReport.txt` |

**Important:** the scenes are generated by `Assets/FirstAidVR/Editor/FirstAidSceneBuilder*.cs`, so **Build All Scenes** overwrites any hand edits to them. To change wording or scoring, edit the scenario assets in `Assets/FirstAidVR/Data/`; a rebuild keeps those. To change a scene permanently, change the builder code.

## Running the automated tests

Open **Window > General > Test Runner > PlayMode > Run All**. There are 22 tests:
- full correct playthroughs of every scenario in both modes
- mistake detection
- pause and the certification time limit
- menu navigation
- the scoring rules
- content consistency

The tests drive the real XR rig and interactors without a headset.
